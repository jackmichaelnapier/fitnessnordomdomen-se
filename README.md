# fitnessnordomdömen.se

Officiell sida med kundomdömen om **FitnessNord**, drivet av FitnessNord. Sidan visar ett urval av
äkta omdömen som publicerats på FitnessNords [Trustpilot-profil](https://www.trustpilot.com/review/www.fitnessnord.com)
och länkar till det fullständiga, aktuella betyget med samtliga omdömen.

Statisk webbplats (en enda självständig HTML-fil, ingen JavaScript) som publiceras via GitHub Pages.

Omdömena tillhör sina respektive författare. Trustpilot är ett varumärke som tillhör Trustpilot A/S.
